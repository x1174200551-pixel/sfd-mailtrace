## 2. 判断口径

1. 已关闭、已取消工单不检查。
2. `first_reply_at` 为空时，检查首次响应 SLA。
3. `first_reply_at` 不为空且 `closed_at` 为空时，检查解决 SLA。
4. 超过截止时间优先按 breach 处理。
5. 未超时但进入 `warning_remain_hours` 窗口时写 warning。
6. 本步只做状态和事件写入；邮件发送提醒后续可基于 `SLA_WARNING/SLA_BREACH` 事件和模板扩展。

## 4. 单测矩阵

| 场景 | 预期 |
|------|------|
| 首次响应截止前进入预警窗口 | 写 `sla_warning_sent=true` 和 `SLA_WARNING` 事件 |
