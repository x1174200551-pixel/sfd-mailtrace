## 浏览器验收结论

1. 企业管理可以查看真实邮箱数、工单数和启停状态，编辑弹窗不会修改未保存数据。
2. 邮箱建单策略页只展示所属企业内模板、SLA、规则组和可用处理人；未完整绑定时显示配置风险。
3. 用户页明确一个角色、一个主部门；企业授权自动包含子邮箱，单邮箱授权可独立选择。
4. 分配规则页以企业规则组组织规则；新建规则不再提供 `DEFAULT` 类型。
5. 工单列表显示企业/邮箱列并支持两级筛选；详情显示建单时策略快照。
6. 客户以企业 + 邮箱地址定位，客户、工作台、收件和发件页面均有企业/邮箱筛选。
7. 角色页没有旧 `dataScopes` 配置入口，页面仅保留菜单和操作权限。

## 环境事件披露

首次启动命令未能按预期关闭 bootstrap 阶段的 Nacos 配置，服务错误连接到 Nacos 解析出的外部 MySQL 5.7，Flyway 已将该库从 schema version 17 迁移到 19。发现后立即停止服务；数据库 DDL 未回滚。之后改为通过环境变量关闭 Nacos，并只使用本地 MySQL 完成开发和验收。

该事件同时说明 V18/V19 已能在 MySQL 5.7 执行，但不能把这次非预期外部变更当作正常测试流程。进入 P6 前需要核对该外部库的 schema history 和迁移后表结构，并确认是否保留本次迁移。

验收完成后停止本次启动的 8080 后端和 5174 前端服务，保留用户原有的其他本地进程不动。
