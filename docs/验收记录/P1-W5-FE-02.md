## 1. 实现内容

- 左侧菜单接入 `SLA策略` 页面，保持当前后台 AppShell 风格。
- 策略列表接入真实接口 `GET /api/v1/sla-policies`。
- 日历下拉接入真实接口 `GET /api/v1/work-calendars`。
- 支持关键字、启停状态、默认策略筛选。
- 支持新建、编辑、保存、启停、设置默认、删除二次确认。
- 支持空列表、加载中、接口失败、无权限四态；四态为真实页面状态，不在正式页常驻展示说明卡。
- 右侧 SLA 预览按绑定工作日历计算工作小时截止时间。

## 2. Service 层口径

本次未改后端 Service，但前端严格按现有 Service 校验与字段实现：

- 默认 SLA 策略在 UI 中保持启用，不允许直接停用。
- 默认 SLA 策略删除按钮禁用，由后端二次保护。
- `resolveHours < responseHours` 时前端阻止保存。
- `warningRemainHours >= responseHours` 时前端阻止保存。
- `calendarId` 必填；无工作日历时保存按钮禁用。
- 保存、启停、默认、删除失败时保留筛选和表单输入。
