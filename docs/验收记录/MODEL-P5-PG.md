## 原型范围

本次新增一份可交互综合原型，覆盖新模型中需要重新确认的四类核心交互：

1. 企业管理：企业列表、业务规模、启停、编辑和停用影响提示。
2. 邮箱策略：所属企业、自动回复模板、SLA、规则组、fallback、配置风险和同企业校验提示。
3. 用户数据授权：单角色、单部门、企业授权、单邮箱授权、管理员全部可见、普通用户空授权提示。
4. 规则与快照：企业规则组、规则明细、历史 `DEFAULT` 退场、邮箱未命中行为、工单策略快照。

通知模板、SLA、工作日历、工单列表、客户、工作台和收发记录继续复用原已确认页面布局；P5 实现时按本原型的企业筛选、企业列和策略归属规则做一致扩展，不为纯字段扩展重复创建整页原型。若开发中出现新的布局或关键交互，再重新触发原型门。

## 谭总确认项

1. 菜单按“企业配置 / 组织权限 / 系统运维”分组。
2. 企业停用不强制停用邮箱，但禁止新业务并保留历史可读。
3. 邮箱未命中默认“保持待分配”，只有显式选择才使用默认处理人。
4. 企业授权自动包含该企业未来新增邮箱；单邮箱授权只包含勾选邮箱。
5. 管理员显示“全部数据可见”，普通用户至少保存一条企业或邮箱授权。
6. 角色页移除旧 `dataScopes`，角色只维护菜单、按钮和接口权限。
