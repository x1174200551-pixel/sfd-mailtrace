## 2. 匹配规则

1. `SUBJECT_KEYWORD`：邮件主题包含匹配值，不区分大小写。
2. `MAILBOX`：匹配来源邮箱 ID；同时兼容来源邮箱地址不区分大小写匹配。
3. `FROM_EMAIL`：匹配客户发件邮箱，不区分大小写。
4. `DEFAULT`：兜底命中，但仍受优先级排序影响。
5. 所有规则按 `priority_order`、`id` 升序，第一条处理人有效的命中规则生效。
