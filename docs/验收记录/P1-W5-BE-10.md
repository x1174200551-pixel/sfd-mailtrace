## 2. 返回字段

| 字段 | 口径 |
|------|------|
| `records` | 当前页客户只读列表 |
| `total` | 符合关键词的客户邮箱总数 |
| `email` | 客户邮箱，来自客户主表或历史工单 |
| `displayName` | 客户展示名，优先客户主表 |
| `lastMailAt` | 最近一封相关邮件时间，按收件/发件时间聚合 |
| `ticketCount` | 该邮箱关联的未删除工单数 |
| `remark` | 客户备注 |
| `createdAt` | 客户主表创建时间或最早工单创建时间 |
