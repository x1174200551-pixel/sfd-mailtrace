## 2. 计算口径

1. 起算时间优先使用客户来信时间 `mailSentAt`；缺失时使用当前建单时间。
2. 若起算时间早于工作开始时间，从当天工作开始时间起算。
3. 若起算时间晚于或等于工作结束时间，从下一个可用工作日的工作开始时间起算。
4. 周末、非工作日、已配置节假日均跳过。
5. 首次响应和解决时限均按工作小时累加；解决时限为空时不写解决截止时间。
6. 首次响应是否达标仍以后台对外回复客户的 `first_reply_at` 为口径，提醒/超时标记放到下一步 `P1-W5-BE-07`。
