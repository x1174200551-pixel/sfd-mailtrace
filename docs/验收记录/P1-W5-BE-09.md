## 2. 返回字段

| 字段 | 口径 |
|------|------|
| `records` | 当前用户作为处理人的待办工单列表 |
| `totalCount` | 当前用户待办总数 |
| `processingCount` | 当前用户处理中待办数 |
| `waitingCustomerCount` | 当前用户待客户回复待办数 |
| `slaOverdueCount` | 当前用户 SLA 超时待办数 |
| `limit` | 本次返回条数限制 |
