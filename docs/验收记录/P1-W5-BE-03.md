## 2. 校验规则

1. 仅管理员可操作 SLA 策略。
2. 首次响应时限、预警阈值、工作日历 ID 必填。
3. 解决时限不能小于首次响应时限。
4. 预警阈值必须小于首次响应时限。
5. 默认 SLA 策略必须启用。
6. 默认 SLA 策略不能停用或删除。
7. 创建/编辑默认策略时执行默认唯一校验；单独设默认时会自动清理其他默认策略。
