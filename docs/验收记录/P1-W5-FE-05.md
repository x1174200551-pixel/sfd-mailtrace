## 1. 实现范围

- 新增左侧菜单 `客户管理`。
- 新增客户只读页面真实前端分支。
- 接入 `GET /api/v1/customers` 客户分页列表。
- 接入 `GET /api/v1/customers/{email}` 客户详情。
- 关联工单通过现有 `GET /api/v1/tickets?keyword={email}` 查询。
- 客户列表支持关键字搜索、分页、选中客户。
- 客户详情展示邮箱、展示名、客户 ID、最近来信、关联工单数、创建时间、备注只读。
- 关联工单展示工单号、主题、状态、SLA、创建时间；点击工单号进入现有工单详情页。
- 权限态：非管理员/处理人显示无客户查看权限。
- 四态：加载中、空列表、接口失败、无权限。
- 第一版不展示新建客户、编辑客户、删除客户入口。

## 2. 口径对齐

- 字段对齐后端 `CustomerVO`：`id`、`email`、`displayName`、`lastMailAt`、`ticketCount`、`remark`、`createdAt`。
- `displayName` 为空时前端回退展示邮箱。
- 仅工单聚合客户 `id` 可为空，详情显示 `仅工单聚合，暂无档案 ID`。
- 备注只展示，不提供编辑。
- 当前没有客户导出接口，前端不展示导出按钮。
- 关联工单不要求客户接口直接返回，按契约使用工单列表关键字检索客户邮箱。
