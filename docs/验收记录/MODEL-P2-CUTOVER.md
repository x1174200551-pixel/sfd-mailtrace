## 切换结论

1. 角色仅承载功能权限，部门不再参与工单业务数据范围；单角色、单部门兼容保持不变。
2. 用户数据范围唯一来自企业/邮箱授权；空授权显式返回空集合或 `1 = 0`，详情及操作返回 403。
3. 管理员可读取停用企业/邮箱的历史数据，但所有新业务操作只允许启用企业下的启用邮箱。
4. `mt_role_data_scope` 表和历史数据完整保留，运行时不再读取或写入，可用于整体应用版本回滚。
