## 1. 实现范围

- 按现有后台风格补齐 `客户管理` 原型页。
- 客户列表：关键字搜索、客户筛选、客户行选中、最近来信、关联工单数。
- 客户详情：客户邮箱、展示名、客户 ID 口径、最近来信、关联工单数、创建时间、备注只读。
- 关联工单：展示工单号、主题、状态、SLA、最近更新；工单号以可点击跳转样式呈现。
- 权限口径：管理员和处理人可访问；无权限态作为页面状态覆盖。
- 四态覆盖：空列表、加载中、接口失败、无权限。
- 只读约束：页面不提供新建客户、编辑客户入口。

## 2. 口径对齐

- 字段对齐后端 `CustomerVO`：`id`、`email`、`displayName`、`lastMailAt`、`ticketCount`、`remark`、`createdAt`。
- 客户来源按后端只读聚合口径：合并客户档案和历史工单邮箱。
- 仅工单聚合客户可能没有客户档案 ID，详情页按邮箱展示。
- 备注第一版只展示，不做编辑。
- 导出为管理员可选动作，处理人仍按只读权限处理。
