## 2. 校验规则

1. 仅管理员可操作节假日。
2. 工作日历、节假日日期、节假日名称必填。
3. 工作日历必须存在。
4. 同一工作日历下节假日日期不能重复。
5. 列表日期范围中，开始日期不能晚于结束日期。
6. 已配置节假日的工作日历不能删除，需先清理节假日。
