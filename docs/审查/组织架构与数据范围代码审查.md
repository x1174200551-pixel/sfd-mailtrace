## 🔴 严重 BUG（2 个）

### BUG-1：`closedToday` 统计使用 `createdAt` 而非 `closedAt`

**影响范围：** `TicketBizService.java:822` + `DashboardService.java:122`

```java
// 当前代码（错误）
wrapper.ge(TicketEntity::getCreatedAt, today.atStartOfDay());

// 应该是
wrapper.ge(TicketEntity::getClosedAt, today.atStartOfDay());
```

**表现：** "今日关闭"统计的是"当天创建的已关闭工单"，而不是"当天关闭的工单"。如果工单昨天创建今天关闭，不计入；如果今天创建明天才关闭，反而被错误计入。

**两处位置：**
- `TicketBizService.java` 第 822-825 行
- `DashboardService.java` 第 122-123 行（完全相同的方法复制）

### BUG-2：`assertAgentOrAdmin()` 在正常注入时角色检查被绕过

**文件：** `DataScopeService.java:43`

```java
private void assertAgentOrAdmin(CurrentUserPrincipal principal) {
    if (permissionService == null && !ROLE_ADMIN.equals(principal.roleCode())
            && !ROLE_AGENT.equals(principal.roleCode())) {
        throw new BusinessException(CODE_FORBIDDEN, "无权操作");
    }
}
```

当 `permissionService` 正常注入时（非 null），左侧条件为 `false`，整个 if 永远不成立——**任何角色都可以通过此检查**。这个方法被 `isAdmin()` 和 `hasAllTicketAccess()` 调用，导致 `CustomerReadonlyService` 中的全量访问判定可能出错。

## 🟡 中高优先级问题（4 个）

### ISSUE-1：DataScopeService 双构造函数反模式

**文件：** `DataScopeService.java:31-41`

```java
// 无参构造函数将 final 字段置 null —— 反模式
public DataScopeService() {
    this.permissionService = null;
    this.departmentMemberService = null;
}
// 同时有 @Autowired 构造函数
```

CGLIB 代理可能调用无参构造函数，导致两个 `final` 字段为 null。代码中不得不充斥大量 `if (permissionService == null)` 的空判断来防御。应移除无参构造函数。

### ISSUE-2：`memberCounts()` 全表扫描

**文件：** `DepartmentService.java:171`

每次加载部门树或单个部门详情时，`memberCounts()` 都会 `SELECT * FROM mt_user_department` 全表加载到内存，再在 Java 中分组计数。部门数量多时性能急剧下降。

**建议：** 改为 SQL 级 `COUNT(*) ... GROUP BY department_id`。

### ISSUE-3：`collectDeptAndChildren()` Java 递归 N+1

**文件：** `DepartmentMemberService.java:76`

每层部门递归执行一次独立 SQL 查询。5 层深度约 121 次查询。已在 S4-02 性能检查中记录，`dept_path` 字段闲置。

### ISSUE-4：`countTickets()` 和 `myTodos()` 大量重复 COUNT 查询

- `stats()` 6 次独立 `SELECT COUNT(*)` + `applyTicketScope` 重复解析
- `summary()` 同上 6 次
- `myTodos()` 4 次 COUNT + 1 次 SELECT = 5 次查询
- `DashboardService` 和 `TicketBizService` 各有一份完全相同的 `countTickets` 实现
