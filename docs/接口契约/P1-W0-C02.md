# P1-W0-C02 W2 邮件网关接口契约

| 项目 | 结论 |
|------|------|
| 契约编号 | P1-W0-C02 |
| 当前状态 | ✅ 已完成 |
| 日期 | 2026-07-23 |
| 前置 | PG-05 ✅、PG-06 ✅、PG-07 ✅ |
| 覆盖范围 | 邮箱配置；拉取日志列表/详情/重试；发送日志列表/详情/重试 |

## 通用规则

- 所有接口需要 `Authorization: Bearer <token>`。
- 第一版仅 `ADMIN` 可访问本契约接口；非管理员返回 `403 / code=40302`。
- 第一版仅支持 IMAP 收信，不开放 POP3。
- SMTP 用于自动回执、分配通知和处理人回复的发信配置。
- `imapPassword`、`smtpPassword` 仅请求时传入；接口响应不回显明文，数据库保存密文。
- 发送失败、拉取失败均不回滚已创建工单；只更新日志状态并允许重试。
- 第一版不做导出。

## POST /api/v1/mailboxes

新建邮箱配置。

### 请求

```json
{
  "mailboxName": "客服支持邮箱",
  "emailAddress": "support@example.com",
  "enabled": true,
  "defaultAssigneeId": null,
  "imapHost": "imap.example.com",
  "imapPort": 993,
  "imapSslEnabled": true,
  "imapUsername": "support@example.com",
  "imapPassword": "app-password",
  "imapFolder": "INBOX",
  "fetchIntervalSec": 120,
  "smtpHost": "smtp.example.com",
  "smtpPort": 587,
  "smtpSslEnabled": true,
  "smtpUsername": "support@example.com",
  "smtpPassword": "app-password",
  "smtpFromName": "客服支持中心",
  "autoReplyEnabled": true,
  "autoReplyTemplateId": null
}
```

### 校验

- `mailboxName`：必填，最大 64 字符。
- `emailAddress`：必填，邮箱格式，唯一，最大 128 字符。
- `imapHost`、`imapUsername`、`smtpHost`、`smtpUsername`：必填。
- `imapPassword`、`smtpPassword`：新建时必填；编辑时为空表示不修改原密文。
- `imapPort`、`smtpPort`：1-65535。
- `fetchIntervalSec`：60-1800 秒。
- `imapFolder`：默认 `INBOX`。

## PUT /api/v1/mailboxes/{id}

编辑邮箱配置。请求体同新建接口。

密码或授权码为空时保留原密文；传入新值时重新加密保存。

## PATCH /api/v1/mailboxes/{id}/enabled

启用或停用邮箱。

```json
{
  "enabled": false
}
```

停用后后台拉取任务不应再拉取该邮箱，历史邮件、工单和日志保留。

## DELETE /api/v1/mailboxes/{id}

逻辑删除邮箱配置。历史邮件、工单和发送记录保留。

## POST /api/v1/mailboxes/{id}/test-connection

测试已保存邮箱连接，并回写 `connectionStatus`。

### 查询参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| testType | string | 否 | `ALL` / `IMAP` / `SMTP`，默认 `ALL` |

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "success": true,
    "connectionStatus": "OK",
    "imapSuccess": true,
    "imapMessage": "IMAP 连接成功，收件文件夹可访问",
    "smtpSuccess": true,
    "smtpMessage": "SMTP 连接成功，账号认证通过",
    "testedAt": "2026-07-23T10:00:00"
  }
}
```

## POST /api/v1/mailboxes/test-connection

测试页面草稿配置，不写入数据库。请求体同新建接口，额外支持：

```json
{
  "testType": "ALL"
}
```

# 二、拉取日志

对应原型：PG-06。数据表：`mt_mail_fetch_log`。

## GET /api/v1/mail-fetch-logs

分页查询 IMAP 拉取任务日志。

### 查询参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| page | number | 否 | 页码，从 1 开始，默认 1 |
| size | number | 否 | 每页条数，默认 10，最大 100 |
| mailboxId | number | 否 | 按邮箱过滤 |
| success | boolean | 否 | `true` 成功，`false` 失败；不传表示全部 |
| hasCreatedTicket | boolean | 否 | `true` 有新建工单，`false` 无新建工单 |
| startedFrom | string | 否 | 开始时间起，ISO-8601 |
| startedTo | string | 否 | 开始时间止，ISO-8601 |

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "records": [
      {
        "id": 1006,
        "mailboxId": 1,
        "mailboxName": "客服支持邮箱",
        "emailAddress": "support@example.com",
        "startedAt": "2026-07-23T11:12:01",
        "finishedAt": "2026-07-23T11:12:08",
        "success": true,
        "fetchedCount": 6,
        "createdTicketCount": 5,
        "linkedCount": 1,
        "durationSec": 7,
        "triggerType": "SCHEDULED",
        "errorMessage": null
      }
    ],
    "total": 6,
    "page": 1,
    "size": 10,
    "pages": 1,
    "summary": {
      "todayFetchCount": 48,
      "todaySuccessCount": 45,
      "todayFailedCount": 3,
      "todayCreatedTicketCount": 126
    }
  }
}
```

### 字段说明

| 字段 | 说明 |
|------|------|
| triggerType | `SCHEDULED` 定时任务 / `MANUAL` 手动触发（含失败重试） |
| durationSec | `finishedAt - startedAt` 秒数；未结束可为 `null` |
| errorMessage | 列表仅返回摘要；详情接口返回完整原文 |

## GET /api/v1/mail-fetch-logs/{id}

拉取任务详情。

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "id": 1006,
    "mailboxId": 1,
    "mailboxName": "客服支持邮箱",
    "emailAddress": "support@example.com",
    "startedAt": "2026-07-23T11:12:01",
    "finishedAt": "2026-07-23T11:12:08",
    "success": true,
    "fetchedCount": 6,
    "createdTicketCount": 5,
    "linkedCount": 1,
    "durationSec": 7,
    "triggerType": "SCHEDULED",
    "errorMessage": null,
    "messages": [
      {
        "messageId": "<a1@client.com>",
        "subject": "无法登录后台",
        "ticketNo": "TCK-20260723-001",
        "ticketId": 101,
        "createdTicket": true
      }
    ]
  }
}
```

### 说明

- `messages` 为本批次处理的邮件样例，便于核对 Message-ID 与关联工单；空拉或连接失败时返回空数组。
- 第一版可先返回最多 20 条样例；完整邮件级列表若需要独立页，后续按收件记录任务扩展。

## POST /api/v1/mail-fetch-logs/{id}/retry

对失败拉取任务触发一次 IMAP 重试。

### 行为

- 仅 `success=false` 的记录允许重试；成功记录返回 `40001`。
- 重试会按原 `mailboxId` 立即入队一次拉取，并**新写**一条 `mt_mail_fetch_log`（`triggerType=MANUAL`）。
- 不修改历史失败记录本身。

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "accepted": true,
    "mailboxId": 3,
    "newFetchLogId": 1007
  }
}
```

```json
  "data": {
    "id": 3005,

    "mailboxId": 2,
    "mailboxName": "销售咨询邮箱",
```

```json
    "createdAt": "2026-07-23T11:10:10",
    "updatedAt": "2026-07-23T11:20:00"
  }

```

### 说明

- `errorMessage` 返回完整 SMTP 错误原文，前端可复制。
- `ticketNo` / `ticketId` 用于跳转工单详情；系统通知无工单时两者均可为 `null`。

## POST /api/v1/mail-send-logs/{id}/retry

手动重试发送。

### 行为

- 允许状态：`FAILED` / `RETRYING` / `PENDING`。
- `SUCCESS` 记录返回 `40001`。
- 若 `retryCount >= maxRetry`，返回 `40001`，提示已达最大重试次数。
- 接受后将状态置为 `RETRYING`，`retryCount + 1`，并尽快执行发送；成功后写 `sentAt`、状态 `SUCCESS`。
- 发送失败不回滚已创建工单。

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "accepted": true,
    "id": 3005,
    "sendStatus": "RETRYING",
    "retryCount": 3
  }
}
```

# 四、错误码

| code | 场景 | HTTP |
|------|------|------|
| 40001 | 参数不合法、密码解密失败、连接测试类型不支持、不可重试的日志状态、超过最大重试次数 | 400 |
| 40302 | 非管理员访问 | 403 |
| 40401 | 邮箱配置 / 拉取日志 / 发送日志不存在 | 404 |
| 40901 | 邮箱地址已存在 | 409 |
