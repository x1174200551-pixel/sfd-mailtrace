## 通用规则

- 所有接口需要 `Authorization: Bearer <token>`。
- 第一版仅 `ADMIN` 可访问邮箱配置接口；非管理员返回 `403 / code=40302`。
- 第一版仅支持 IMAP 收信，不开放 POP3。
- SMTP 用于自动回执、分配通知和处理人回复的发信配置。
- `imapPassword`、`smtpPassword` 仅请求时传入；接口响应不回显明文，数据库保存密文。

## POST /api/v1/mailboxes

新建邮箱配置。

### 请求

```json
{
  "mailboxName": "客服支持邮箱",
  "emailAddress": "support@example.com",
  "enabled": true,
  "defaultAssigneeId": null,
  "imapHost": "imap.example.com",
  "imapPort": 993,
  "imapSslEnabled": true,
  "imapUsername": "support@example.com",
  "imapPassword": "app-password",
  "imapFolder": "INBOX",
  "fetchIntervalSec": 120,
  "smtpHost": "smtp.example.com",
  "smtpPort": 587,
  "smtpSslEnabled": true,
  "smtpUsername": "support@example.com",
  "smtpPassword": "app-password",
  "smtpFromName": "客服支持中心",
  "autoReplyEnabled": true,
  "autoReplyTemplateId": null
}
```

### 校验

- `mailboxName`：必填，最大 64 字符。
- `emailAddress`：必填，邮箱格式，唯一，最大 128 字符。
- `imapHost`、`imapUsername`、`smtpHost`、`smtpUsername`：必填。
- `imapPassword`、`smtpPassword`：新建时必填；编辑时为空表示不修改原密文。
- `imapPort`、`smtpPort`：1-65535。
- `fetchIntervalSec`：60-1800 秒。
- `imapFolder`：默认 `INBOX`。

## PUT /api/v1/mailboxes/{id}

编辑邮箱配置。请求体同新建接口。

密码或授权码为空时保留原密文；传入新值时重新加密保存。

## PATCH /api/v1/mailboxes/{id}/enabled

启用或停用邮箱。

```json
{
  "enabled": false
}
```

停用后后台拉取任务不应再拉取该邮箱，历史邮件、工单和日志保留。

## DELETE /api/v1/mailboxes/{id}

逻辑删除邮箱配置。历史邮件、工单和发送记录保留。

## POST /api/v1/mailboxes/{id}/test-connection

测试已保存邮箱连接，并回写 `connectionStatus`。

### 查询参数

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| testType | string | 否 | `ALL` / `IMAP` / `SMTP`，默认 `ALL` |

### 响应

```json
{
  "code": 0,
  "message": "ok",
  "data": {
    "success": true,
    "connectionStatus": "OK",
    "imapSuccess": true,
    "imapMessage": "IMAP 连接成功，收件文件夹可访问",
    "smtpSuccess": true,
    "smtpMessage": "SMTP 连接成功，账号认证通过",
    "testedAt": "2026-07-23T10:00:00"
  }
}
```

## POST /api/v1/mailboxes/test-connection

测试页面草稿配置，不写入数据库。请求体同新建接口，额外支持：

```json
{
  "testType": "ALL"
}
```

## 错误码

| code | 场景 | HTTP |
|------|------|------|
| 40001 | 参数不合法、密码解密失败、连接测试类型不支持 | 400 |
| 40302 | 非管理员访问 | 403 |
| 40401 | 邮箱配置不存在 | 404 |
| 40901 | 邮箱地址已存在 | 409 |

## 实现对应

- 后端实现：`MailboxController`、`MailboxService`、`MailboxEntity`、`MailboxMapper`、`MailPasswordCipher`。
- 前端实现：AppShell 内容区的邮箱配置页面，覆盖统计、列表、筛选、新增、编辑、启停、删除、连接测试、空态、加载态、错误态、权限态。
- 数据：`mt_mailbox` 保存 IMAP/SMTP 配置，`imap_password_enc` 和 `smtp_password_enc` 只存密文。
